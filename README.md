# KeeCharlotte

Personal Portfolio Website · [Visit](https://keecharlotte.github.io/#home)

## 網站定位

這是人生履歷與個人作品紀錄，不是專案進度看板。專案頁介紹創作動機、問題意識、核心理念、代表性取捨、個人角色及已發生的經驗；讀者需要實作與驗證細節時，再進入對應的公開作品集。

## 內容怎麼維護

功能新增、程式重構、缺陷修復、測試數量、build／commit／版本或尚未完成項目變動，**不觸發本網站同步更新**，也不新增自動抓取程式庫進度的機制。

只在專案定位、重要設計取捨、個人責任或值得保存的經驗有實質改變時，才更新相關介紹。開始年月屬歷史事實；工具列記錄專案使用經驗，不是目前依賴清單、熟練程度或獨立實作能力的證明。

案例以當時發生的觀察與選擇書寫。後來修復程式不會抹去原經驗；若原紀錄有事實錯誤，仍應修正。介紹不保證功能已完成、測試通過、專業採信或產品可正式使用；也不以模糊敘述把設計目標寫成已完成成果。

最新實作、測試及適用限制由 LedgerTrail、文明重建等公開作品集各自維護。網站保留穩定的作品集入口，不必跟著每次提交更換快照或重抄證據。不得複製私人程式、SQL、帳密、存檔或原始日誌。

## 修改範圍與發布

兩個專案的卡片與詳細介紹集中於 `assets/experience.js`；`index.html` 保留對應的基本資料與共用標籤，版面由既有 HTML／`assets/experience.css` 承接。不為內容更新改動其他人生紀錄、導覽或版面。

修改前確認最新 main 與既有工作；多檔修改在隔離候選完成。發布前檢查 JavaScript、兩專案切換、章節／返回導覽、窄螢幕及非目標頁面，核對差異後以非強制推送整合，再回讀內容。

不新增或手動執行 Actions。既有 GitHub Pages 會自動發布；Git 提交、部署結果與實際頁面讀回分開確認。
