## 帳跡介紹維護

[帳跡頁](https://keecharlotte.github.io/#ability/Software/0)的卡片、介紹及來源連結集中在 `assets/experience.js`；沿用 `index.html` 與 `assets/experience.css` 的導覽及版面。

網站只摘要已核准公開的作品集。更新帳跡時，同步盤點日期、版本、統計口徑、案例與限制，將佐證連到對應公開快照；「View full portfolio」保留最新作品集入口。不得把歷史測試改成最新通過，也不複製私人程式、SQL、帳密或原始日誌。

發布前在本地檢查 JavaScript、章節導覽、專案切換與窄螢幕呈現；保留其他作品內容。不要新增或手動執行 Actions。既有 GitHub Pages 會自動發布，部署結果與 Git 提交分開確認。
